# Rencanaku.ai
aplikasi pendamping perencanaan proyek berbasis AI. Aplikasi membantu pengguna mengembangkan gagasan menjadi persyaratan yang terstruktur, dokumen konteks proyek, keputusan teknis, arsitektur, rencana implementasi, tugas, prompt coding agent, serta siklus perbaikan prompt berdasarkan hasil dan kesalahan yang dilaporkan dari coding agent eksternal.
